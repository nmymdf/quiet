# 一鍵安靜

看電影、聽音樂會時，點一下就讓 Android 手機全部安靜；再點一下恢復原狀。作者：ArchieKUO

- 鈴聲靜音、勿擾不留任何例外（鬧鐘、重複來電也不放行）、通知不亮螢幕、螢幕調到最暗
- 來電自動拒接（含聯絡人、連續打來的），對方轉語音信箱；通話紀錄保留，App 裡列出剛才是誰打來
- 關閉時，鈴聲模式、勿擾與勿擾例外、亮度都還原成開啟前的樣子
- 省電模式：安靜中提供「去打開」按鈕（系統不讓 App 自動開關）
- 忘了關的保險：約 4 小時後自動恢復
- 三種開關方式：App 大圓鈕、桌面小工具、下拉快速設定的「一鍵安靜」
- 安靜中提醒「手錶也開劇院模式」

做不到的（Android 不開放）：飛航模式、自動開關省電、Always On Display、手錶劇院模式、國家級警報。

## 編譯

推到 `main`，GitHub Actions 會自動編譯，APK 放在 `apk` 分支，檔名含版本號（例如 `quiet-v0.1.apk`）。
簽章用 `app/archie.keystore`（與鬧鐘 App 同一把，鬧鐘 repo 裡本來就公開），之後每版都用它，才能覆蓋更新。
