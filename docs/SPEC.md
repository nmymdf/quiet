# 一鍵安靜 規格

## 開啟時
1. 記下原本的鈴聲模式、勿擾狀態、亮度與自動亮度
2. 鈴聲模式 → 靜音
3. 勿擾 → 記下原本的勿擾例外（NotificationManager.Policy），改成「沒有任何例外」（鬧鐘、媒體、系統、重複來電、星號聯絡人都不放行），並且通知進來不亮螢幕、不跳出、不閃燈（FULL_SCREEN_INTENT、PEEK、LIGHTS、AMBIENT），再開勿擾（INTERRUPTION_FILTER_PRIORITY）
   - v0.1 用 INTERRUPTION_FILTER_NONE（完全靜音），三星仍放行鬧鐘，所以改成這樣
4. 亮度 → 手動、最低
5. 來電過濾（CallScreeningService）：安靜中所有來電直接拒接（setRejectCall），保留通話紀錄、不跳未接通知，App 記下時間、號碼、聯絡人名稱（最多 30 筆）
   - 有「讀取聯絡人」權限，聯絡人打來才會交給 App 過濾（Android 規定）
6. 約 4 小時後自動恢復（AlarmManager 非精確鬧鐘；重開機後補排）

## 關閉時
依序還原勿擾例外 → 勿擾 → 鈴聲模式 → 亮度與自動亮度。

## 省電模式
系統不讓一般 App 開關省電模式。安靜中畫面有「省電模式」一列：沒開時顯示「去打開」，按了打開系統的省電設定頁；關閉安靜後，若省電是安靜期間才開的，提醒「省電模式還開著」並可去關閉。

## 開關入口
App 大圓鈕、桌面小工具（3×1，可調大小）、快速設定磚。

## 第一次設定
勿擾權限、修改系統設定、讀取聯絡人、來電過濾角色。側載 App 若遇「受限設定」，到應用程式資訊 → ⋮ → 允許受限設定。

## 做不到
飛航模式、自動開關省電模式、Always On Display、手錶劇院模式（無公開 API）、國家級警報。

## 手錶
Galaxy Wearable 需打開「與手機同步勿擾」，手錶才會跟著勿擾。
